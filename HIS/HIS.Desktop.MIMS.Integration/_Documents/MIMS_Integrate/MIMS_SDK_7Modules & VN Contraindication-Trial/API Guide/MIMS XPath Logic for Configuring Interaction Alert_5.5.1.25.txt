--------------------------------------------------------------------------------------------------------------------------------------
XPath Expression Checks on all InteractionResponse.xml
--------------------------------------------------------------------------------------------------------------------------------------
Objective:

Given below are the XPath Expressions that can be used to run below checks on the Result.xml to
a. Find if there are any interaction alerts for any "specific drug" or "severity" or "irrespective of any drug or severity" in the response.xml
b. These flags can be used to pop-up interaction alert or over-ride reasoning window in your application only when this XPATH Flag is "True"
c. XPATH Flags 
	(i) if XPATH Count > 0 = True
	(ii) if XPATH Count = 0 = False

Example or one use case:

If a specific drug being prescribed has any interaction with other drugs prescribed in same order or with previously prescribed Medications which are still active, then use the below XPath logic to run that check before applying the stylesheet. Hence if the XPath expression reports count > 0 then the Result.xml output has interaction for the specific medicine being prescribed, only then you proceed triggering pop-up window to display interaction alert or same flag can be used to trigger over-ride reasoning window via your application else not.

Applicable Modules:

These logics cover “Drug to Drug”, “Drug to Allergy”, “Drug to Health”, "Duplicate Therapy", "Duplicate Ingredient", "Drug Pregnancy", "Drug Lactation", "Drug Dose" Interaction Alerts

(i) XPath for "Drug to Drug Interaction":
----------------------------------------
To check if any Drug to Drug Interaction alert exists in the Result.xml

For Specific Drug whose GUID = {864EBD9F-9789-4451-908A-C6A354E9FA24}
“count(//Interaction/*[@reference='{864EBD9F-9789-4451-908A-C6A354E9FA24}' and not(@Mirror)]/Route/*/Route/ClassInteraction|//Interaction/*/Route/*[@reference='{864EBD9F-9789-4451-908A-C6A354E9FA24}' and not(@Mirror)]/Route/ClassInteraction)"

For Specific Drug whose GUID = {864EBD9F-9789-4451-908A-C6A354E9FA24} and Severity 'Severe' or 'Moderate' or 'Minor' or 'Caution'

“count(//Interaction/*[@reference='{864EBD9F-9789-4451-908A-C6A354E9FA24}' and not(@Mirror)]/Route/*/Route/ClassInteraction/Severity[@name='Severe' or @name='Moderate' or @name='Minor' or @name='Caution']|//Interaction/*/Route/*[@reference='{864EBD9F-9789-4451-908A-C6A354E9FA24}' and not(@Mirror)]/Route/ClassInteraction/Severity[@name='Severe' or @name='Moderate' or @name='Minor' or @name='Caution'])"

Irrespective to any specific drug and Severity
“count(//Interaction/*[not(@Mirror)]/Route/*/Route/ClassInteraction| //Interaction/*/Route/*[not(@Mirror)]/Route/ClassInteraction)”

Irrespective to any specific drug but with specific Severity
“count(//Interaction/*[not(@Mirror)]/Route/*/Route/ClassInteraction/Severity[@name='Severe' or @name='Moderate' or @name='Minor' or @name='Caution']|//Interaction/*/Route/*[not(@Mirror)]/Route/ClassInteraction/Severity[@name='Severe' or @name='Moderate' or @name='Minor' or @name='Caution'])”
